这轮究竟改变了什么？

旧方案先用 Python 把 Jerry 贴在载具上，再用 img2img 反复修补。新方案不输入任何图片，让模型直接决定动作和构图；当文字解释能力足够强时，错误的草图反而是障碍。

实验范围有限：只有两个场景、两个模型和少量种子。更好的驾驶姿势不代表稳定复刻每一处经典动画细节。
